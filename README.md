# 百名城めぐり 🏯

日本100名城をめぐって「登城」を記録する Android アプリです（Kotlin + Jetpack Compose）。

## あそびかた
- **いちらん**：100城を地方べつ・番号順に表示。未登城／登城ずみで絞りこみ、現在地から近い順にも並べられます。
- **ちず**：100城を地図にピン表示（赤＝登城ずみ、灰＝未登城）。ピンをタップするとお城の詳細。
- **登城**：お城の近く（約1.2km、山城など広い城跡はもっと広め）で「📷 写真をとって登城！」。
  - 前に行ったお城は「🖼 前に行ったときの写真で記録」で、ギャラリーの写真から登録できます。
  - 「🧭 道案内」で地図アプリのナビを開けます。
- **称号**：登城数で 足軽(1) → 足軽大将(10) → 侍大将(25) → 城代(50) → 大名(75) → 天下人(100)。
- **地方制覇**：地方のお城をすべて登城すると 👑。
- **お城クイズ**：お城ごとに最大10問の4択クイズ（登城していなくても挑戦できます）。
  満点をとったお城には 🎓 がつきます。問題は `app/src/main/java/com/kabata/sanpo/quiz/` にあり、
  `番号|問題|正解|ハズレ1|ハズレ2|ハズレ3` の形式で簡単に追加・修正できます。
- **アルバム**：登城写真の一覧。まちがえた記録は削除できます。

記録と写真は端末の中だけに保存されます。地図は OpenStreetMap を使っています。

## 注意
- お城の座標はおおよその位置です。チェックイン範囲を広めにして誤差を吸収しています。
  ずれていて登城できないお城があれば、`app/src/main/java/com/kabata/sanpo/data/Castles.kt` の座標を直してください。
- 「日本100名城」は公益財団法人日本城郭協会が選定したものです。アプリを一般公開する場合は、名称の扱いを確認してください。

## APK の入手
GitHub Actions の「Build APK」→ Artifacts の `hyakumeijo-debug-apk`。

# にっぽん観光めぐり 📍（`kanko/`）

47都道府県の観光スポット（各県10か所前後、愛知・三重は16か所）をめぐって記録する、もう一つのアプリです。

- **スポット**：地方 → 都道府県を選んで一覧。現在地があれば近い順。「📍 近く」で周辺30か所。
- **ちず**：全スポットをピン表示（青＝訪問ずみ、赤＝未訪問）。
- **チェックイン**：スポットの近く（基本1km、広い場所はもっと広め）で写真をとって記録。前に行った場所は写真から登録。
- **🧭 道案内**／**🔎 調べる**（Google検索）ボタン。
- 訪れた都道府県数、県ごとの制覇（👑）、称号。

スポットのデータは `kanko/src/main/java/com/kabata/kanko/data/Spots*.kt` に
`都道府県|名前|絵文字|緯度|経度|ひとこと|半径m` の形式で入っています。座標はおおよその位置です。

APK は Releases の `kanko.apk`。

# 英語あなうめパズル 🔤（`eigo/`）

英文の空欄に入る単語を、文字タイルをならべて完成させるパズルです。

- 4レベル（中1 → 中学 → 高校 → 受験・TOEIC）× 6ステージ × 10問 ＝ 240問。上のレベルほどダミー文字が増えます。
- 💡ヒント（先頭から1文字ずつ）、↩クリア、⏭パス。正解すると英文を読み上げ（🔊）。
- ミス・ヒント・パスが少ないほど星が増える（最大★3）。クリアで次のステージが開きます。
- まちがえた問題は「📝 ふくしゅう」でまとめて練習できます。

問題は `eigo/src/main/java/com/kabata/eigo/Questions.kt` に `レベル|英文（空欄は ___）|答え|日本語訳` の形式で入っています。
APK は Releases の `eigo.apk`。
